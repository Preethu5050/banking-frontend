# RexBank — Frontend

React frontend for the RexBank Banking Application.

## 🌐 Live Demo
https://banking-frontend-coral.vercel.app

## 🛠️ Tech Stack
- React.js
- Axios
- React Router DOM
- Vercel (Deployment)

## ✨ Features
- Beautiful dark themed UI
- JWT Authentication
- Real-time balance display
- Deposit & Withdraw
- Transaction History
- Export CSV

## 🔗 Backend API
https://github.com/Preethu5050/banking-finance-api

## 🚀 Run Locally
```bash
git clone https://github.com/Preethu5050/banking-frontend.git
cd banking-frontend
npm install
npm start
```
